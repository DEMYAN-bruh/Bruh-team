# Bruh-team

## Présentation

Bruh-team est un projet étudiant de développement d'une application locale de suivi sportif. Elle doit permettre de créer des programmes d'entraînement, d'enregistrer ses séances et de suivre sa progression.

Le projet est réalisé en équipe avec la méthodologie Agile Scrum. Le sprint actuel porte sur la gestion des programmes.

## Objectif

Développer une application utilisable en local pour gérer ses entraînements et retrouver facilement ses données sportives.

## État du projet

Le projet est actuellement en phase de conception. Les fonctionnalités prévues ne sont pas encore développées et aucune version installable n'est disponible.

## Fonctionnalités prévues

- Créer des programmes d'entraînement
- Consulter et rechercher des programmes
- Enregistrer ses séances
- Consulter son historique
- Gérer ses données sportives

## Contribution

- Créer une branche depuis `main` au format `feature/BT-<numéro>-description`.
- Associer les commits au ticket Jira correspondant (ex. `BT-1 : formulaire de création`).
- Ouvrir une Pull Request avant de fusionner dans `main`.
- Faire relire chaque Pull Request par un autre membre de l'équipe.
- Mettre à jour la documentation si les fonctionnalités ou les besoins évoluent.
- Ne considérer une fonctionnalité comme terminée qu'après sa validation.
